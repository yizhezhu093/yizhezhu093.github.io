# Yizhe Zhu — academic website

Published at https://yizhezhu093.github.io/ using GitHub Pages.

This site uses plain HTML and CSS, with no build step or JavaScript runtime.

## Editing

- `index.html`: biography, research interests, and contact information.
- `publications.html`: preprints and papers.
- `teaching.html` and the individual course HTML files: teaching archive.
- `travel.html`: talks and visits.
- `style.css`: shared appearance and responsive layout.
- The homepage embeds the portrait from the original website.

The material was migrated from the owner's Google Sites website in September 2026. Paper statuses and external resource links are preserved from that source.

## Local preview

Run `python3 -m http.server 8000` in this directory, then open http://localhost:8000.

## Publishing

In Settings → Pages, deploy from the `main` branch, `/ (root)` folder. Updates to that branch publish automatically. The `.nojekyll` file prevents Jekyll processing.
